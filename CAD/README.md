# CAD

The full-assembly STEP file for the V4 design is **not in this folder yet**.

It was exported from the V4 Part Studio in Onshape as STEP AP242
(millimeters), file `racing-drone-V4-assembly.step` (2 MB). It is stored as a
file tab in the
["racing drone" Onshape document](https://cad.onshape.com/documents/57b30fe062deae315745b482/w/472712d7beec1ac27b6e40ff/e/95e0f703430a6ff77fdf3e90)
(in the "Frame and Drone" folder) — open the document, click the
`racing-drone-V4-assembly.step` tab, and click Download. Drop the file in this
folder as `CAD/racing-drone-V4-assembly.step` once downloaded.

The individual 3D-printed parts are in `STL/` as STL files.
